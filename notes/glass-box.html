A glass box, not a black box

20 August 2026 · 2 min read

Every agent framework collects the same complaint: too much abstraction, hidden control flow, painful to debug. Something happens on your behalf, and you cannot find where.

glia is the opposite bet. Every model call, every tool call, every state transition is a plain object: you can log it, snapshot it, replay it. No hidden control flow. The whole loop fits in one file you can read in an evening.

Modern techniques — planning, memory, tools — are here, but as opt-in primitives, not as default magic. You turn on what you need, and you can point at the line where it happens. The core has no dependencies.

The cost is honest: glia will not decide for you what the agent should be. It does not hide the decision — it shows it. For debugging and for understanding that is what you want; for "build me an agent with one button" it is not.
