A glass box, not a black box

20 August 2026 · 4 min read

Every agent framework collects the same complaint: too much abstraction, hidden control flow, painful to debug. Something happens on your behalf, and you cannot find where. When the agent does the wrong thing, you are left re-running an API and hoping the bug shows up again.

glia is the opposite bet: the control flow is the thing you are allowed to see.

Every step is a plain object

Every model call, every tool call, every state transition is a plain object. You can log it, snapshot it, replay it. There is no hidden loop deciding things behind the scenes — the loop is code you wrote, over objects you can inspect.

Replay is the point. Given the same recorded steps, you get the same run: you debug an agent by replaying the exact sequence that broke, not by re-rolling the dice against a live model. A bug you can reproduce is a bug you can fix.

Primitives, not magic

Modern techniques — planning, memory, tools, retrieval — are here, but as opt-in primitives, not as default behaviour. You turn on what you need, and you can point at the line where it happens. Nothing is added to your agent that you did not add yourself.

The whole loop fits in one file you can read in an evening. That is the test the design is built to pass: not "how much does it do out of the box", but "how long until you understand all of it".

The core has no dependencies

The core has zero dependencies. You can read the entire control flow without chasing it through five packages, each with its own idea of what an agent is. Like the rest of the DrobyshevDev libraries, it is typed and tested in CI on Linux, macOS and Windows — the guarantees are checked, not described.

The honest cost

The cost is real: glia will not decide for you what the agent should be. It does not hide the decision — it shows it, and hands it back to you. For "build me an agent with one button" that is the wrong trade. For debugging, for understanding, and for shipping something you can still reason about in six months, it is the right one.
