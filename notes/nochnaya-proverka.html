The night check

4 August 2026 · 2 min read

You open the logs at night, though the deploy finished six hours ago and everything is green.

The fear is not about the server. Checking is a way to feel control for a minute where there is none: the server can fall over at any moment, and an open tab will not change that.

Anxiety always offers an action. The action brings relief for about ten minutes, then asks to be repeated, and the threshold rises. That is how it sets: not because it helps, but because it helps quickly.

There is one test for it: if a check changes nothing you do, it is not a check.
