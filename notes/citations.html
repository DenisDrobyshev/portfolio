Citations you can check

20 August 2026 · 5 min read

An LLM answers a legal question and cites an article of the law. It sounds confident. The problem is that the article can be invented: the right format, the right tone, a norm that does not exist. For legal work that is a disqualifying flaw. A wrong reference is worse than "I don't know", because it costs the reader the time to discover it is wrong.

praxis is built around one refusal: it will not hand you a citation it has not checked.

Extractive by default

The default answer is extractive: it is the text of the law itself, not the model's paraphrase. It cannot hallucinate, because it generates nothing — it quotes. The corpus is real and bounded: six codes ship in the repository — civil, tax, labour, criminal, housing and administrative offences — the civil one alone running to 1,712 articles and 4,717 provisions, with a cross-reference graph between them.

Every citation is verified

A separate step checks each citation. An NLI model decides whether the cited norm actually supports the claim, not just resembles it in words. A reference that sounds plausible but is off-point is cut, not sent to the user. This is the difference between a system that retrieves and a system that is allowed to be trusted: verification, not resemblance.

Retrieval is measured, not asserted

Retrieval is hybrid — lexical plus dense — with a cross-encoder reranker on top. Quality is not claimed in prose, it is pinned by an eval on a golden set and recomputed on every run:

  • recall@5 — 0.92 on the full corpus
  • MRR — 0.94

The whole thing runs locally with no keys required:

docker compose up app        # → http://localhost:8077

FastAPI, Postgres with pgvector, 40 tests, Apache-2.0.

The model is a convenience, not the source of truth

An optional LLM layer exists — it makes the answer read more smoothly. But it passes the same citation check as the extractive one, so it cannot smuggle in a reference the verifier would reject. The law is the source of truth; the model is a nicer way to read it.

Judicial practice is the next pipeline rather than something already shipped, and the code texts are marked in the corpus as pending a check against the official publication. Saying what is not yet verified is part of the same rule: a system about citations has no business hiding its own.
