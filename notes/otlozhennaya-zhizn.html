The postponed life

14 July 2026 · 2 min read

Once I finish this project, I will start living properly.

The list does not end: the degree, then the job, then the move, then something else. The condition stays one step ahead, because it moves with you.

This is not about planning. Planning is fine. It is about the present being declared a draft: now does not count, counting starts later.

But later is also now, just a different one. And you will arrive there with the same habit.

There is a simple test: if you removed the condition, what would change today? If nothing, the condition was never about living. It was about permission to start.
